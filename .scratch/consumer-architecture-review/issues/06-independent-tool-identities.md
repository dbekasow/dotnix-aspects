# 06: Decouple tool identities from primary mail

**What to build:** Let a consumer choose whether changing a primary mailbox should also change Git authorship or the vault account.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A representative home's explicit Git and vault identities stay unchanged when its primary mailbox changes; the consumer can still deliberately reuse an address.
- [ ] Preserve the private consumer's effective identities and update template guidance and superseded shared-identity expectations to match ADR 0009. Do not require mail setup just to supply a tool identity.
