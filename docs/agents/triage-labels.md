# Triage labels

These roles are stored locally as `Status:` values.

| Role            | Local value     | Meaning                        |
| --------------- | --------------- | ------------------------------ |
| needs-triage    | needs-triage    | Maintainer evaluation needed   |
| needs-info      | needs-info      | Waiting for clarification      |
| ready-for-agent | ready-for-agent | Fully specified for agent work |
| ready-for-human | ready-for-human | Human implementation required  |
| wontfix         | wontfix         | Will not be actioned           |

These are triage roles. Wayfinding claim and resolution states
are defined separately in `issue-tracker.md`.
